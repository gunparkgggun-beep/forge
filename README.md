# FORGE DEVELOPMENT policy pages

This folder contains draft Terms of Service and Privacy Policy pages for your Discord application.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `forge-development-policies`).
2. Upload `terms-of-service.md` and `privacy-policy.md`.
3. In repository Settings → Pages, enable GitHub Pages from your main branch.
4. Open the published pages and copy their public URLs.
5. In Discord Developer Portal → General Information, paste the URLs into Terms of Service URL and Privacy Policy URL.

Before publishing, replace the contact placeholders and make sure the privacy policy accurately describes what your bot actually collects and stores. You cannot use the local files themselves as public Discord URLs.
